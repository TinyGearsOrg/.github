<p align="center"><b>Small but useful, well maintained tools</b></p>

TinyGears makes small tools that each solve one problem, and keeps them in good shape. A project here aims to:

- stay small and focused, with as few dependencies as it can,
- come with tests and continuous integration, and say in its documentation what it does and what it does not,
- stay maintained: issues are read, dependencies are kept up to date, and releases follow semantic versioning.

## Projects

| Project | What it is |
|---|---|
| [uom](https://github.com/TinyGearsOrg/uom) | Typed quantities and units of measurement for Java: a native API with typed products and a JSR-385 implementation on one exact engine. |
| [cubit](https://github.com/TinyGearsOrg/cubit) | A dimensional-analysis calculator on uom: units, typed products and exact conversions, as a CLI and a web app. Run it with jbang. |

## Earlier projects

These are not under active development and are kept for reference.

| Project | What it is |
|---|---|
| [tinydiff](https://github.com/TinyGearsOrg/tinydiff) | A small Kotlin library for diff-like comparisons of files and streams, using Myers' O(ND) algorithm. |
| [tinydiff-cli](https://github.com/TinyGearsOrg/tinydiff-cli) | A command line tool for tinydiff. |
| [bat](https://github.com/TinyGearsOrg/bat) | The Bytecode Analysis Toolkit: reads and writes JVM class files and dex files. |
| [shade](https://github.com/TinyGearsOrg/shade) | A Gradle plugin that creates fat JARs, applies file transforms, and relocates and minimizes packages; the Gradle version of Maven's Shade plugin. |

[tinygears.org](https://www.tinygears.org).
